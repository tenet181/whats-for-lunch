# 中午吃什么 · 微信小程序

麓坊中心 15 分钟午餐地图小程序版，由 H5 版本（React + Vite）改写为原生小程序。

## 功能

- **地图**：示意点位图，点击圆点查看详情
- **列表**：按方向（华阳 / 正兴 / 万安 / 略远）筛选
- **🎲 抽一家**：15 分钟圈内随机抽选
- **详情弹层**：招牌菜、一句话点评、拆迁提醒
  - 「复制地址」：一键复制「店名：详细地址」到剪贴板
  - 「大众点评」：小程序无法直接打开外部网页，点击后复制点评链接，粘贴到浏览器 / 大众点评 App 打开

## 目录结构

```
├── app.js / app.json / app.wxss   小程序入口
├── project.config.json            开发者工具项目配置（测试号 appid）
├── sitemap.json
├── data/restaurants.js            11 家餐厅数据（与 H5 版同源）
└── pages/index/                   唯一页面：三个 Tab + 详情弹层
```

## 使用

1. 微信开发者工具 → 导入项目 → 选择本目录
2. 预览 / 真机调试即可
3. 正式发布前把 `project.config.json` 里的 `appid` 换成你自己的小程序 AppID

## 数据维护

改店增店只动 `data/restaurants.js`：字段与 H5 版一致（`x/y` 是 680×340 画布上的示意图坐标）。
